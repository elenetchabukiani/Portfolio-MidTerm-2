# ელენე ჭაბუკიანის პორტფოლიო (React & React Router)

თანამედროვე, კომპონენტური და სრულად რესპონსიული პორტფოლიო ვებ-აპლიკაცია, აგებული **React 18**-ის, **React Router v6**-ის, **Tailwind CSS**-ისა და **JSONPlaceholder REST API**-ს ბაზაზე.

---

## 🚀 პროექტის გაშვება (Getting Started)

პროექტის ლოკალურად გასაშვებად ტერმინალში გაუშვით:

```bash
# 1. დეველოპმენტ სერვერის გაშვება
npm run dev
```

ლოკალური მისამართი: [http://localhost:5173/](http://localhost:5173/)

პროექტის დასაბილდად (Production Build):
```bash
npm run build
```

## 📑 საიტის გვერდები & მარშრუტები (Routes)

1. **მთავარი (`/`)** — `HeroSection` (მისალმება, ავატარი, ფოტო) და `QuickOverview` (სწრაფი მიმოხილვის ბარათები).
2. **ჩემ შესახებ (`/about`)** — ბიოგრაფია, მისია, ტექნოლოგიური უნარების ბადე და განათლების ბარათი.
3. **სერვისები (`/services`)** 🌟 *ახალი გვერდი* — ვებ-დეველოპმენტის ტარიფები, **ინტერაქტიული ბიუჯეტის კალკულატორი** (დინამიური ფასის გამოთვლით), კლიენტების გამოხმაურებები (`GET /comments`) და FAQ აკორდეონი.
4. **პროექტები (`/projects`)** — შესრულებული სამუშაოები, ტექნოლოგიური ტეგები, GitHub და Live ბმულები.
5. **ბლოგი (`/blog`)** 🌟 *ახალი გვერდი* — ტექნოლოგიური სტატიები (`GET /posts`), კატეგორიების ფილტრაცია, **ცოცხალი ძებნა**, წაკითხვის მოდალი კომენტარების სექციით (`GET /comments?postId={id}`) და ახალი სტატიის დამატება (`POST /posts`).
6. **თანამშრომლები (`/employees`)** — თანამშრომელთა სრული სია (`GET /users`), **ცოცხალი ძებნა**, პოსტებისა (`/posts`) და დავალებების (`/todos`) მოდალი, ახალი წევრის დამატება (`POST /users`) და წაშლა (`DELETE /users/{id}`).
7. **კონტაქტი (`/contact`)** — საკონტაქტო ბარათები და ინტერაქტიული ფორმა (`POST /posts`).

## 📌 დავალების მოთხოვნების შესრულება

| მოთხოვნა | რეალიზაცია პროექტში |
|---|---|
| **1. საიტი React-ის გამოყენებით** | აპლიკაცია სრულად აგებულია **React 18**-ზე Vite-ის გარემოში. |
| **2. მთავარი გვერდის დაყოფა კომპონენტებად** | `HomePage` დაყოფილია მოდულარულ კომპონენტებად: `HeroSection`, `QuickOverview`, `Navbar`, `Footer`. |
| **3. განმეორებადი ვიზუალური ელემენტები** | შექმნილია მრავალჯერ გამოყენებადი კომპონენტები: `Card`, `Badge`, `Button`, `SectionHeader`, `SearchBar`, `Modal`. |
| **4. Routing (react-router)** | დაინსტალირებულია `react-router` და `react-router-dom`. აწყობილია 7 სრულფასოვანი მარშრუტი (`/`, `/about`, `/services`, `/projects`, `/blog`, `/employees`, `/contact`, `*`). |
| **5. მინიმუმ ერთი ახალი გვერდი** | დამატებულია **3 ახალი გვერდი**: `EmployeesPage` (`/employees`), `BlogPage` (`/blog`) და `ServicesPage` (`/services`). |
| **6. JSONPlaceholder REST API ინტეგრაცია** | რეალიზებულია: `GET /users`, `GET /posts`, `GET /todos`, `GET /comments`, `POST /users`, `POST /posts`, `DELETE /users`. |
| **7. ძებნის (Search) ფუნქციონალი** | `EmployeesPage`-სა და `BlogPage`-ზე ინტეგრირებულია ცოცხალი ძებნა (`SearchBar`), რომელიც რეალურ დროში ფილტრავს მონაცემებს. |
